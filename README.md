# MechaRise

## Story site (Eclipse of the Iron Gods)

Open `site/index.html` in Chrome or Edge. Pages: Home, Versions, Story, Characters, Mechas, World, Design Doc.
Turn on **Edit** (top right) to change any text, image or list. Click **Connect folder** once and pick the
MechaRise folder so **Save** writes `site/content.js` directly. Uploaded images go to `site/assets/uploads/`.
Each save keeps the previous versions of changed entries (History button in edit mode).
**The website is the single source for story, characters, mecha personalities and regions.** The GDD (`docs/GDD_ECLIPSE_OF_THE_IRON_GODS.md`, also in the Design Doc tab) covers gameplay, systems, lore rules and production.
