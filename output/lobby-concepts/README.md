# MechaRise lobby scenery concepts

Generated using the built-in image generation tool. These are concept pictures for choosing composition; the playable lobby has not been changed in this step.

## Shared prompt direction

One wide 16:9 detailed hand-painted 2.5D anime RPG environment per concept, elevated orthographic game view and coherent building angles. Six readable connected facilities: white/orange mech hangar with small white/lavender mech, red/gold command HQ with cyan hologram, blue-roof medical clinic, amber supply shop, red-roof crew home, cyan deployment gate. Original world, restrained sci-fi additions, lush gardens, warm late-afternoon daylight, small chibi crew, no UI, labels, text, watermark or flat board layout.
